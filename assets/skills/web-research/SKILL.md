# 联网查证与引用来源

## 何时使用

用户要外部事实、最新信息、官方文档，或明确要求提供来源与引用。

## 步骤

1. 用 `web_search` 搜索，一次选最相关的关键词。
2. 需要正文时用 `web_fetch` 抓具体页面，不要凭标题猜测内容。
3. 只采用工具真实返回过的信息。工具没给的内容，要么再查一次，要么如实说明查不到。

## 引用规则

最终回答必须列出所用来源，每条一行，格式为标题加完整网址：

```
来源：
- 标题 A — https://example.com/a
- 标题 B — https://example.com/b
```

- 只引用工具实际返回过的网址，逐字照抄，不改写、不补全、不编造。
- 没有引用过的网址不得出现在回答里。
- 工具没有返回可用结果时，直接说明未查到，并列出请求过的关键词。

## 验收标准

- 回答正文用到了检索到的信息。
- 结尾有功用来源列表，每条都来自 `web_search` 或 `web_fetch` 的真实返回。
