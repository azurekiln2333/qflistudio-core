# 缺陷修复循环

## 步骤

1. 用 run_command 复现问题，记录真实退出码和报错原文。
2. 用 read_file 读取报错指向的文件，不要凭记忆改。
3. 用 todo 列出修复步骤，每步一行。
4. 用 edit_file 做最小改动。oldText 必须取自刚读到的原文。
5. 用 run_command 重跑**同一个**命令，比对退出码。
6. 退出码仍非零时回到第 2 步。不要在一次失败后换命令绕开问题。

## 约束

- 不复现就不算修好。
- 不删除失败用例来让检查通过。
- 命令连续两次给出同样的错误时，先 read_file 确认文件当前内容，再决定下一步。
- 结论必须引用真实输出：退出码、报错行或输出片段。

## 收尾

向用户报告：复现命令、原因、改动文件、修复后的命令与退出码。
